# Project Claude Instructions

## Goal
Проект AI-Digest публикует регулярные дайджесты по теме тахографов, карт тахографа и перевозок.

Цель:
- объяснять актуальные изменения и новости;
- давать практическую пользу водителям и транспортным компаниям;
- формировать экспертность в нише тахографов.

## Scope
Тематика:
- карты тахографа;
- тахографы;
- БДД и режим труда и отдыха;
- изменения законодательства и штрафы;
- практика перевозок.

## Digest Rules

### Отбор новостей
- только актуальные (последняя неделя);
- практическая ценность;
- влияние на водителей или перевозчиков;
- достоверные источники.

### Формат выпуска
- 1 файл: src/content/blog/YYYY-MM-DD-digest.md
- 3–5 новостей в одном выпуске
- каждая новость: заголовок + краткое объяснение + вывод
- 100–150 слов на новость

### Стиль
- просто и понятно;
- без лишней юридической сложности;
- без маркетинга;
- только факты + польза;
- если есть сомнения в актуальности — указать это

## Pipeline (Draft)

Этапы:
1. поиск новостей
2. отбор
3. написание
4. обложка
5. публикация

На текущем этапе:
- не подключать внешние API
- использовать заглушки

## Structure

- статьи будут храниться тут: src/content/blog/
- пайплайн будет расположен: src/scripts/pipeline/
